## 3. 踩坑记录（可写进报告"问题与解决"一节）

- **现象**：按图 9 之前的设置把 PA0 的 GPIO mode 选成了 Output Open Drain，程序下载后 LED 始终不亮。
- **原因**：开漏输出只有"拉低到 GND"的能力，输出高电平时引脚是高阻态（悬空）。PA0 上没有外加的上拉电阻，接在 PA0 上的 LED 拿不到 3.3 V 高电平，所以永远不亮。
- **解决**：把 GPIO mode 改成 **Output Push Pull**（推挽输出），推挽既能拉高到 3.3 V、也能拉低到 0 V，LED 正常亮灭。
- **参考图**：`09-PA0输出参数-开漏错误示例.png`、`10-PA0输出参数-推挽输出.png`。
